# py.
A multi-utility Python CLI app featuring a password generator, smart calculator, notes, games, and file management."

## ⚡ Features
- 🔒 **Password Generator:** Customizable character sets + strength checker.
- 🧮 **Smart Calculator:** Fast mathematical operations.
- 📝 **Quick Notes & File Saving:** Export passwords and notes directly to `.txt` files.
- 🎲 **Games & Utilities:** Coin flip, dice roll, countdown timer, and guessing game.
